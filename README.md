# Personal Resume Site

> Historical Project — not recently verified

This repository contains an early static resume website built with HTML, CSS,
JavaScript, and Bootstrap-era frontend assets.

The published GitHub Pages site is available at
[danieljucke.github.io/My-resume-](https://danieljucke.github.io/My-resume-/).
Content and external links may no longer reflect the current professional
profile; the newer [portfolio repository](https://github.com/Danieljucke/Portfolio)
is the preferred public presentation.

## Preview locally

```bash
python -m http.server 8000
```

Open <http://localhost:8000>.
